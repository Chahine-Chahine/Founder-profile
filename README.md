# Chahine Chahine — Founder Portfolio

A single-page portfolio for career fairs and outsourcing conversations. Plain HTML/CSS/JS, no build step.

## Run locally
Open `index.html` in a browser, or run `npx serve .`.

## Deploy
Import the repo into Vercel (framework preset: **Other**) or enable GitHub Pages. No build command is needed.

## Before the fair — edit these
- `script.js` → `CONFIG.email` (and optionally `phone`): used by the contact form, footer and vCard download.
- `index.html` → About photo: replace the `CC` placeholder with `assets/chahine.jpg`.
- `index.html` → Forevergreen case study: replace the placeholder brief with the real client story.
- Hero KPI panel and project mockups use **illustrative demo data**. Replace them with real numbers if you have them.
